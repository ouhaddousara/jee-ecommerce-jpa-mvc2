\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}
Ce rapport présente la réalisation d'« Atlas Boutique », une application web de commerce électronique construite
selon le patron MVC2 (servlets contrôleurs, vues JSP/JSTL) avec une couche de persistance JPA (EclipseLink)
sur MySQL. Le périmètre retenu couvre l'internaute (client ou administrateur), la vitrine, les catégories, les
produits et le panier ; la commande est volontairement laissée en perspective.

Le document explique les décisions plutôt que le code : héritage \code{SINGLE\_TABLE}, verrouillage optimiste,
règles métier portées par l'entité \code{Panier}, transactions centralisées dans un seul composant, injection CDI
sur Tomcat, protection contre les failles courantes (CSRF, XSS, injection SQL, fixation de session) et
vérification par \nbChecks{} contrôles automatisés complétés d'un parcours manuel. Un épisode technique
(incompatibilité entre EclipseLink 2.7.5 et les classes compilées pour Java 17) est détaillé car il illustre
l'importance de lire les journaux au démarrage.

\textbf{Mots-clés :} Java EE, MVC2, servlets, JSP, JSTL, JPA, EclipseLink, CDI, Weld, MySQL, Tomcat, sécurité web.
